# AI 使用记录

使用工具：Codex。

本次借助 Codex 完成代码实现、测试用例、模型接入和文档初稿整理。真实运行时也通过 Codex CLI 调用模型，让它根据工具结果选择下一步。

提交要求、文档表达和最终取舍由我把关。说明文字围绕实际做法和运行结果展开，避免把项目写成一份功能宣传稿。实现中重点检查了超时以后是否重新估算、失败步骤是否被记为完成、素材引用是否能对应原文。

修改过程中处理了两个具体问题：一个是新版本检查失败以后，旧版本的通过状态不能继续代表当前稿；另一个是标题和画面描述也可能出现没有依据的效果数字，因此检查范围扩展到了这些字段。

测试结果和模型执行过程保存在 `examples/`，可以按 README 的命令重新运行。
